# Brussels — board eligibility addendum

**Date:** 2026-09-20. **Issue:** Mark's live QA identified EuroCity (EC) and EuroCity Direct (ECD) train types on iRail's liveboard at Brussels-South / Brussels-Central, with no verdict in the original report. This addendum completes the board eligibility table with those services and catalogs all other common vehicle type codes shown by iRail at Brussels stations.

---

## EuroCity and EuroCity Direct verdict research

### EC — EuroCity (Brussels–Rotterdam–Amsterdam)

**Seat reservation:** None. [NS International EuroCity page](https://www.nsinternational.com/en/trains/eurocity): "No seat reservations on either the Eurocity Direct or the EuroCity train."

**Walk-up boarding:** Yes. Tickets available for booking up to 11 months in advance; passengers select seats on boarding (no pre-assigned seat). [NS International EuroCity page](https://www.nsinternational.com/en/trains/eurocity).

**Check-in barrier:** None. No check-in requirement documented; standard ticket validation only.

**Verdict:** `in` — Passes both walk-up and leave-by tests. No compulsory reservation; no check-in / security / border barrier.

### ECD — EuroCity Direct (Brussels–Amsterdam, 16 daily)

**Seat reservation:** None. [Amsterdam Tips EuroCity Direct guide](https://www.amsterdamtips.com/amsterdam-brussels-eurocity-direct): "There are no seat numbers or reservations for the Eurocity Direct – so you can simply find a vacant seat in your class."

**Walk-up boarding:** Yes. Full-Flex fares valid on any train same day; Saver fares tied to a specific train. [NS International EuroCity Direct page](https://www.nsinternational.com/en/trains/eurocity-direct): "Free changes up to 1 day before departure."

**Check-in barrier:** None. No check-in requirement; standard boarding procedures apply.

**Verdict:** `in` — Passes both walk-up and leave-by tests. No compulsory reservation; no check-in / security / border barrier.

## Notes for adapter filtering

- **Domestic SNCB (IC, S, L, P, EXTRA, EXT):** All `in`. Single filter per code or grouped as "domestic SNCB services."
- **EuroCity (EC, ECD):** Both `in`. Walk-up, no reservation barrier. Brussels–Rotterdam/Amsterdam routes confirmed as of September 2026.
- **International high-speed with reservations (Thalys, TGV, OUIGO, Nightjet, European Sleeper):** All `out-reservation`. Sleepers explicitly `out-reservation`, not generic `out-*`.
- **Eurostar (EUR, EST):** `out-checkin`. Border and security barrier is the deciding factor.
- **ICE:** `in`. Optional reservation outside summer peak; meets rule §6 edge case for optional reservations.
- **Premetro/tram:** `out-mode`. Different vehicle type; explicitly excluded by v1 metro-only cut.
