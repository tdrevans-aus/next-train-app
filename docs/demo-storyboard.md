# Demo storyboard — 15–30s (store + social)

**Owners:** Simon (script) · Tim (film / edit)  
**Status:** Ready to shoot when UI matches leave-by hero  
**Use:** Play/App Store preview (if used), Instagram/Reels, Reddit, FB groups, QR landing later  

---

## 1. Creative goal (Ruth §3.5)

Hero moment: **kitchen / home → “Leave by / Leave in …” with live delay honesty** — not a trip planner flex.

**Audio:** Soft ambient or mute + captions (many watch muted).  
**Length:** **20s** ideal (cutdown 15s; cut-up 30s with end card).

---

## 2. Shot list (20s version)


| Time | Visual | On-screen text / VO (optional) |
| ---- | ------ | ------------------------------ |
| 0:00–0:03 | Phone face-up on kitchen bench / keys / coffee mug (real Perth morning vibe) | When should I leave? |
| 0:03–0:07 | Unlock → Next Train → Journey mode; big leave countdown settles | Leave in 12 min |
| 0:07–0:12 | Subtle delay/status or scheduled vs live moment (honesty) | Live times · delays included |
| 0:12–0:16 | Quick cut: Near me board OR journey name/route line | Your commute · saved |
| 0:16–0:20 | End card: wordmark + **Next Train** + “Unofficial Transperth companion” + “Free on Play / App Store” (when live) | — |

**Don’t show:** Settings spaghetti, ad consent sheets, placeholder ads, debug overlays, official Transperth branding.

## 5. Tim production notes

- Film on a real device; airplane mode off if you need live data — or use a known-good fixture for a clean take

- Keep fingers out of the leave number  
- Export 1080×1920 (vertical) + 16:9 crop for YouTube/store if needed
